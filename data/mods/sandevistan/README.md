# Sandevistan

A Cataclysm: Bright Nights mod that adds the Sandevistan, the spinal speedware from *Cyberpunk: Edgerunners*. The core mod is Lua + JSON and runs on a stock engine. Two optional features need the C++ patch that ships with it:

- translucent afterimage copies of the character (tiles);
- sound effects.

## Content

| What | ID | Summary |
| --- | --- | --- |
| CBM | `bio_sandevistan_mk1` | Civilian unit: ×2.5 speed, others act 50% of the time, overheats after ~20 turns, 2 kJ per action |
| CBM | `bio_sandevistan` | Military unit: ×4 speed, others act 10% of the time, overheats after ~13 turns, 5 kJ per action |

Both CBMs can be picked at character creation on the Bionics tab, for 4 and 7 points. They need bionic power, so pick a power storage CBM there too:

- Mk.1 (60 kJ to activate): `bio_power_storage` (100 kJ) is enough.
- Military (125 kJ to activate): needs `bio_power_storage_mkII` (250 kJ).

Both CBMs also appear in the `bionics_mil`, `bionics_sci` and `bionics_op` item groups.

## Effects

- **The world turns green.** While engaged, the unit applies an effect with `EFFECT_NIGHT_VISION`, which switches the renderer to its green night-vision filter.
- **Time slows down.**
  - The avatar gets `SPEED` / `MOVE_COST` / `ATTACK_COST` enchantments.
  - Monsters and NPCs only gain 50% (Mk.1) or 10% (military) of their speed in moves per turn, via `on_monster_do_turn` / `on_npc_do_turn`, so they act that fraction of the time.
- **Energy.** The engine charges `act_cost` once on activation and `react_cost` every turn. The mod also charges a per-action cost for every step and melee swing, because a boosted character takes several actions per game turn. When power runs out, the unit shuts down.
- **Rainbow afterimages, like in the anime.** Every step leaves an afterimage; the hue cycles red → orange → yellow → green → cyan → blue → violet.
  - Tiles with the engine patch: a translucent copy of the whole character, gear included, filled with its hue. Older copies fade out.
  - ASCII, or an unpatched engine: a coloured `@` field. The mod picks this automatically.
- **Sound** (engine patch + `SOUND=ON` build). Three original synthesized effects in `sound/`:
  - activation: a deep "time stops" drop with a glassy shimmer and heartbeats;
  - deactivation: a snap back up to speed;
  - overheat: crackle plus a warning tone.
- **Overheating.** At 100% heat the unit force-shuts down: nosebleed, stun, pain and a 90-turn cooldown. Heat bleeds off while the unit is idle.
- **Sidebar widget** with state, a heat gauge and a power gauge, shown only while a Sandevistan is installed.
- NPCs cannot run the unit: heat is only tracked for the player, so activation is refused (and refunded) for NPCs.

## Tileset (UnDeadPeople style)

`tileset.json` and `gfx/` hold a `mod_tileset` with the same compatibility list as UDP Redux (`UNDEAD_PEOPLE_BASE`, `UNDEAD_PEOPLE`). It works with MSX++UnDeadPeopleEdition, with or without the UDP Redux mod, and uses no sprite ids that Redux overrides.

- CBM item icons: a steel Mk.1 spine with cyan nodes, and a gunmetal military spine with red heat sinks and green nodes.
- `fd_sande_trail_1..7`: chibi afterimage silhouettes in UDP proportions, one per hue. These are only used without the engine patch.
- `overlay_effect_sande_vision`: an animated green halo with rainbow speed streaks while engaged.
- `overlay_effect_sande_heat`: rising heat shimmer while the spine is hot.

All art is original and generated by a script, not copied from UDP. Other tilesets fall back to the generic CBM sprite (`looks_like`) and ASCII fields.

## Engine limits

- Afterimages are drawn per tile: there is no smooth motion between tiles, and every copy faces the character's current direction.
- The screen filter colour is fixed by the engine to green.
- Sounds are resolved relative to the mod's own `sounds.json`, so the mod keeps its audio in `sound/` and works from `data/mods` as well as from the user mod folder.
- Translations ship in `lang/` (ru, de, fr, es, ja, ko, zh_CN). Lua messages and the sidebar widget go through `locale.gettext`, so re-extract strings with `lang/extract_mod_strings.sh` after changing them.

## Testing

```sh
./cataclysm-bn-tiles --check-mods sandevistan
./tests/cata_test-tiles --mods=sandevistan "[sandevistan]"
./tests/cata_test-tiles "[afterimage]"
```

Quick in-game check: Debug menu → Player → Bionics, install `bio_sandevistan`, add power and activate it.
